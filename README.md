# afterlight-dark
Afterlight Dark, an Ubuntu Terminal theme for long coding sessions with muted blue/green/sand palette that give a distinctive wasteland/military feel. As of Ubuntu 25, the default Terminal is `Ptyxis`.

## Prerequisite

```
sudo apt install dconf-cli
```

### Install

Download the repo, then `cd` into it and run the installer:

```
./install-afterlight-dark.sh
```

It creates a separate `Afterlight Dark` profile, so it won't overwrite your existing Terminal configuration.
